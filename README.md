To run this project locally:

1. Make sure you have Ruby version 2.7.0 or higher, RubyGems, GCC and Make installed. See [the Jekyll website]([https://pages.github.com/](https://jekyllrb.com/docs/installation/#requirements)) for more details on these requirements and how to install them.
2. Clone this repository onto your computer with the command `git clone https://github.com/a-pretty-terrifying-project/feminist-horror-co-occurences.git` - or use any of the other clone options you can see after clicking the "code" button on the upper right of this repository.
3. Move into the newly cloned repository.
4. Run the command `gem install jekyll bundler` to install Jekyll and its bundler.
5. Finally, run `bundle exec jekyll serve`, then navigate to http://localhost:4000 to view the site!
